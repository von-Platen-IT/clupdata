# Erstellen-Menü

## Übersicht

Das Erstellen-Menü bietet schnellen Zugriff auf die Erstellungsfunktionen für alle Entitätstypen. Die verfügbaren Einträge passen sich dynamisch dem aktuellen Kontext an.

## Menüpunkte

### Mitglied

Öffnet den Dialog zum Erstellen eines neuen Mitglieds.

**Siehe auch**: [Mitglieder - Mitglied erstellen](02_mitglieder.md#mitglied-erstellen)

### Leistung

Öffnet den Dialog zum Erstellen einer neuen Leistungsart.

**Siehe auch**: [Leistungen - Leistung erstellen](03_leistungen.md#leistung-erstellen)

### Rechnungslegung

Öffnet den **Rechnungslegungs-Assistenten** zum Erstellen von Beiträgen für
viele Mitglieder auf einmal (z. B. Monatsbeiträge). Sie können zwischen vier
Abrechnungsarten wählen und alles vorab in einer Vorschau prüfen.

**Siehe auch**: [Rechnungslegung](08_rechnungslegung.md)

### Ware

Öffnet den Dialog zum Erstellen eines neuen Artikels.

**Siehe auch**: [Waren - Ware erstellen](05_waren.md#ware-erstellen)

## Tipps

- Die gleichen Funktionen sind auch über das **"+"-Symbol** in den jeweiligen Screens verfügbar
- Die Tastenkürzel können für schnelles Erstellen verwendet werden
