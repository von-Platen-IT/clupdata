# Bemerkungen

## Übersicht

Bemerkungen sind Notizen, die zu verschiedenen Entitäten (Mitglieder, Leistungen, Waren, Beiträge, Rechnungen) hinzugefügt werden können. Sie dienen der Dokumentation wichtiger Informationen.

## Funktionen

### Bemerkung erstellen/bearbeiten

1. Wählen Sie einen Datensatz in der Liste aus
2. Im unteren Bereich erscheint der **Bemerkungsbereich**
3. Geben Sie **Titel** und **Text** ein
4. Klicken Sie auf **Speichern**

### Felder

| Feld | Beschreibung |
|------|-------------|
| Titel | Kurze Überschrift (max. 200 Zeichen) |
| Text | Detaillierte Beschreibung (max. 10.000 Zeichen) |
| Datum erstellt | Wird automatisch gesetzt |

## Wo können Bemerkungen verwendet werden?

- **Mitglieder**: Notizen zu Mitgliedern
- **Leistungen**: Beschreibung der Leistungsart
- **Waren**: Produktbeschreibung
- **Beiträge**: Informationen zum Beitrag
- **Rechnungen**: Notizen zur Rechnung
- **Preise**: Preis-Beschreibung

## Tipps

- Bemerkungen sind optional
- Der Titel sollte kurz und aussagekräftig sein
- Leere Bemerkungen werden nicht gespeichert
