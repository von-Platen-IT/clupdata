# Start - Dashboard

## Übersicht

Das Dashboard ist die Startseite der Anwendung und bietet eine visuelle Begrüßung mit dem Logo und dem Namen "PhraPhikanet Organizer".

## Funktionen

- **Logo-Anzeige**: Das Vereinslogo wird zentral dargestellt
- **App-Name**: "PhraPhikanet Organizer" wird prominent angezeigt
- **Versionsnummer**: Die aktuelle App-Version wird im Seitenmenü angezeigt

## Navigation

Über die Seitenleiste links können Sie zu allen Funktionen der Anwendung navigieren:

| Symbol | Funktion | Beschreibung |
|--------|----------|-------------|
| 🏠 | Start | Zurück zum Dashboard |
| 👥 | Mitglieder | Mitgliederverwaltung |
| 📄 | Leistungen | Leistungsarten verwalten |
| 💰 | Beiträge | Beitragsverwaltung |
| 📦 | Waren | Artikelverwaltung |
| 🧾 | Rechnungen | Rechnungsverwaltung |
| 📅 | Kursplan | Terminübersicht |

## Tipps

- Klicken Sie auf das Menü-Symbol oben links, um die Seitenleiste zu erweitern oder zu reduzieren
- Die Einstellungen erreichen Sie über das Zahnrad-Symbol unten in der Seitenleiste
