# Start – Dashboard

## Übersicht

Das Dashboard ist die Startseite von **ClupData** und bietet eine visuelle
Begrüßung mit dem Vereinslogo und dem Anwendungsnamen.

## Funktionen

- **Logo-Anzeige**: Das Vereinslogo wird zentral dargestellt
- **Versionsnummer**: Die aktuelle Version wird im Seitenmenü angezeigt

## Navigation

Über die Seitenleiste links können Sie zu allen Funktionen der Anwendung
navigieren:

| Symbol | Funktion | Beschreibung |
|--------|----------|-------------|
| 🏠 | Start | Zurück zum Dashboard |
| 👥 | Mitglieder | Mitgliederverwaltung |
| 📄 | Leistungen | Leistungsarten und Preise verwalten |
| 💰 | Beiträge | Beitragsverwaltung und Zahlungen |
| 📦 | Waren | Artikelverwaltung |
| 🧾 | Rechnungen | Rechnungen für Warenverkäufe |
| 📅 | Kursplan | Kurszeiten im Wochenplan |
| 🛡️ | Sicherung & Wiederherstellung | Datensicherung und Restore |
| ❓ | Hilfe & Dokumentation | Diese Dokumentation |

**Schnellzugriff**: Über die [Tastenkürzel](22_tastenkuerzel.md) springen Sie
mit `Alt + 1` bis `Alt + 9` direkt in die einzelnen Bereiche.

## Tipps

- Klicken Sie auf das Menü-Symbol oben links, um die Seitenleiste zu erweitern
  oder zu reduzieren
- Die Einstellungen erreichen Sie über das Zahnrad-Symbol unten in der
  Seitenleiste
- Neu in ClupData? Die [Übersicht](00_index.md) zeigt Ihnen die
  ersten Schritte
