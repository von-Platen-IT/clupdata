# Waren

## Übersicht

Im Bereich "Waren" verwalten Sie alle Artikel, Bekleidung und Trainingsgeräte, die über den Point-of-Sale (POS) verkauft werden können. Jeder Artikel kann detaillierte Eigenschaften wie Größe, Farbe, Material und Lagerbestand haben.

## Funktionen

### Datenübersicht

Die Warenliste zeigt folgende Informationen:

| Spalte | Beschreibung |
|--------|-------------|
| Bezeichnung | Name des Artikels |
| Kategorie | Artikelgruppe (z.B. "Bekleidung", "Schutzausrüstung") |
| Bestand | Aktueller Lagerbestand |
| Brutto (€) | Verkaufspreis (brutto) |
| Netto (€) | Nettopreis (automatisch berechnet) |
| Aktiv | Status des Artikels (aktiv/inaktiv) |

### Ware erstellen

1. Klicken Sie auf das **"+"-Symbol** in der Symbolleiste
2. Oder nutzen Sie das Menü **Erstellen > Ware**
3. Füllen Sie die folgenden Bereiche aus:

#### Bereich: Allgemein
- **Bezeichnung**: Name des Artikels (z.B. "Karate-Gi weiß")
- **Kategorie**: Artikelgruppe (z.B. "Bekleidung")
- **Beschreibung**: Detaillierte Beschreibung
- **Aktiv**: Checkbox für aktiven/inaktiven Status

#### Bereich: Eigenschaften
- **Größe**: Z.B. S, M, L, XL oder numerische Größen
- **Farbe**: Farbe des Artikels
- **Geschlecht**: Unisex, Herren, Damen, Kinder
- **Material**: Z.B. Baumwolle, Polyester, Leder
- **Gewicht (kg)**: Für Versandkosten
- **Einheit**: Verkaufseinheit (Stück, Paar, Set)

#### Bereich: Preise & Bestand
- **Einkaufspreis (€)**: Netto-Einkaufspreis
- **Bruttopreis (€)**: Brutto-Verkaufspreis
- **Nettopreis (€)**: Wird automatisch berechnet
- **Bestand**: Aktueller Lagerbestand
- **Mindestbestand**: Untergrenze für Nachbestellung

#### Bereich: Logistik & Hersteller
- **Lieferant**: Name des Lieferanten
- **Hersteller**: Herstellerfirma
- **Artikelnr. HF**: Hersteller-eigene Artikelnummer

#### Bereich: Bemerkung
- **Titel**: Titel der Bemerkung
- **Text**: Detaillierte Beschreibung

### Ware bearbeiten

1. Wählen Sie eine Ware in der Liste aus
2. Doppelklicken Sie auf den Eintrag
3. Ändern Sie die gewünschten Felder
4. Klicken Sie auf **Speichern**

### Ware löschen

1. Wählen Sie die zu löschende Ware aus
2. Klicken Sie auf das **Löschen-Symbol**
3. Bestätigen Sie die Löschung im Dialog

## Tipps

- Inaktische Waren werden im POS nicht mehr angezeigt
- Der **Mindestbestand** hilft bei der Nachbestellungsplanung
- Die MwSt wird automatisch aus den Stammdaten berechnet
- Preise werden als Snapshot in Rechnungen gespeichert
