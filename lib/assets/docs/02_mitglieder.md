# Mitglieder

## Übersicht

Die Mitgliederverwaltung ist das zentrale Modul zur Pflege aller Mitgliederdaten. Hier können Sie neue Mitglieder anlegen, bestehende Daten bearbeiten und Mitglieder verwalten.

## Funktionen

### Datenübersicht

Die Mitgliederliste zeigt folgende Informationen:

| Spalte | Beschreibung |
|--------|-------------|
| Name | Nachname des Mitglieds |
| Vorname | Vorname des Mitglieds |
| Ort | Wohnort des Mitglieds |
| Telefon | Telefonnummer |
| E-Mail | E-Mail-Adresse |
| Vertragsart | Art der gebuchten Leistung |
| Beitrag | Höhe des Beitrags |

### Mitglied erstellen

1. Klicken Sie auf das **"+"-Symbol** in der Symbolleiste
2. Oder nutzen Sie das Menü **Erstellen > Mitglied**
3. Füllen Sie die folgenden Bereiche aus:

#### Bereich: Person
- **Anrede**: Herr, Frau, Divers oder Keine
- **Vorname**: Pflichtfeld
- **Name**: Pflichtfeld
- **Geburtsdatum**: Datum der Geburt
- **Alter**: Wird automatisch berechnet
- **Geschlecht**: Männlich, Weiblich, Divers

#### Bereich: Kontakt
- **PLZ**: Postleitzahl
- **Ort**: Wohnort
- **Telefon 1**: Haupttelefonnummer
- **Telefon 2**: Weitere Telefonnummer
- **E-Mail**: E-Mail-Adresse

#### Bereich: Vertrag
- **Kontierung**: Datum der Vertragskontierung
- **Leistung**: Gewählte Leistungsart
- **Laufzeit von**: Beginn des Vertrags
- **Laufzeit bis**: Ende des Vertrags (wird automatisch berechnet)

### Mitglied bearbeiten

1. Wählen Sie ein Mitglied in der Liste aus
2. Doppelklicken Sie auf den Eintrag oder klicken Sie auf **Bearbeiten**
3. Ändern Sie die gewünschten Felder
4. Klicken Sie auf **Speichern**

### Mitglied löschen

1. Wählen Sie das zu löschende Mitglied aus
2. Klicken Sie auf das **Löschen-Symbol**
3. Bestätigen Sie die Löschung im Dialog

### Bemerkungen

Zu jedem Mitglied können Sie Bemerkungen speichern:

1. Wählen Sie ein Mitglied aus
2. Im unteren Bereich erscheint der **Bemerkungsbereich**
3. Geben Sie Titel und Text ein
4. Klicken Sie auf **Speichern**

### Vertrag starten

Der Dialog "Vertrag starten" ermöglicht:

- Setzen des Kontierungsdatums
- Auswahl der Leistung
- Automatische Berechnung der Laufzeit

## Tipps

- Die **Suchfunktion** in der Tabellenüberschrift ermöglicht schnelles Finden
- Die Spalten können **sortiert** und **gefiltert** werden
- Die zuletzt ausgewählte Zeile wird beim Verlassen gespeichert
