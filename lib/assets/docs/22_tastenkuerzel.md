# Tastenkürzel

## Übersicht

Die Anwendung unterstützt verschiedene Tastenkürzel für eine effiziente Bedienung.

## Globale Tastenkürzel

| Tastenkürzel | Funktion |
|--------------|----------|
| `ESC` | Dialog schließen |
| `Enter` | Speichern (in Dialogen) |

## Dialog-Tastenkürzel

### Edit-Dialoge

| Tastenkürzel | Funktion |
|--------------|----------|
| `ESC` | Dialog schließen ohne Speichern |
| `Enter` | Änderungen speichern |

**Hinweis**: `Enter` wird nur ausgeführt, wenn kein mehrzeiliges Textfeld oder Dropdown-Menü fokussiert ist.

## Tipps

- Die Tastenkürzel funktionieren in allen Edit-Dialogen
- Bei mehrzeiligen Textfeldern fügt `Enter` einen Zeilenumbruch ein
