# Tastenkürzel

## Übersicht

ClupData ist für die effiziente Bedienung mit der Tastatur ausgelegt. Auf
**macOS** wird statt **Strg** die **Command-Taste (⌘)** verwendet.

## Globale Tastenkürzel

| Tastenkürzel | Funktion |
|--------------|----------|
| `ESC` | Dialog schließen |
| `Enter` | Speichern (in Dialogen) |
| `F1` | Hilfe öffnen |
| `F2` | Über die Anwendung |

## Menü-Funktionen

| Tastenkürzel | Funktion |
|--------------|----------|
| `Strg + ,` | Einstellungen öffnen |
| `Strg + Q` | Anwendung beenden |
| `Strg + B` | Sicherung & Wiederherstellung (Backup) |
| `Strg + R` | Wiederherstellen (Restore) |
| `Strg + E` | CSV-Export |
| `Strg + I` | CSV-Import |
| `Umschalt + F1` | Rechnungslegung (Assistent) |
| `Umschalt + F2` | Rechnungserstellung Verkauf |

## Schnell-Erstellen

| Tastenkürzel | Funktion |
|--------------|----------|
| `Strg + Umschalt + B` | Neuen Beitrag erstellen |
| `Strg + Umschalt + R` | Neue Rechnung erstellen |
| `Strg + Umschalt + M` | Neues Mitglied erstellen |
| `Strg + Umschalt + L` | Neue Leistung erstellen |
| `Strg + Umschalt + W` | Neue Ware erstellen |

## Navigation

| Tastenkürzel | Funktion |
|--------------|----------|
| `Alt + 1` … `Alt + 9` | Direkt zu den Bereichen der Seitenleiste |

## Dialog-Tastenkürzel

### Edit-Dialoge

| Tastenkürzel | Funktion |
|--------------|----------|
| `ESC` | Dialog schließen ohne Speichern |
| `Enter` | Änderungen speichern |

**Hinweis**: `Enter` wird nur ausgeführt, wenn kein mehrzeiliges Textfeld oder
Dropdown-Menü fokussiert ist.

## Tipps

- Die Kürzel sind in den Menüs direkt am jeweiligen Eintrag angezeigt
- Bei mehrzeiligen Textfeldern fügt `Enter` einen Zeilenumbruch ein
- Auf macOS entspricht **Strg** immer der **Command-Taste (⌘)**
