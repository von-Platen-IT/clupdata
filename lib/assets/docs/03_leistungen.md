# Leistungen

## Übersicht

Im Bereich "Leistungen" verwalten Sie die verschiedenen Leistungsarten und Vertragsarten, die Ihren Mitgliedern zur Verfügung stehen. Jede Leistung hat einen Namen, eine Laufzeit und einen Preis.

## Funktionen

### Datenübersicht

Die Leistungsliste zeigt folgende Informationen:

| Spalte | Beschreibung |
|--------|-------------|
| Name | Bezeichnung der Leistung |
| Laufzeit | Art der Laufzeit (einmalig, monatlich, quartalsweise, jährlich) |
| Brutto (€) | Bruttopreis der Leistung |
| Netto (€) | Nettopreis (wird automatisch berechnet) |

### Leistung erstellen

1. Klicken Sie auf das **"+"-Symbol** in der Symbolleiste
2. Oder nutzen Sie das Menü **Erstellen > Leistung**
3. Füllen Sie die folgenden Felder aus:

#### Bereich: Leistung
- **Name**: Bezeichnung der Leistung (z.B. "Mitgliedsbeitrag Erwachsene")
- **Laufzeit**: Art der Laufzeit
  - `einmalig`: Einmalige Zahlung
  - `monatlich`: Monatliche Wiederholung
  - `quartalsweise`: Vierteljährliche Wiederholung
  - `jaehrlich`: Jährliche Wiederholung

#### Bereich: Preis
- **Bruttopreis (€)**: Der Bruttopreis der Leistung
- **Nettopreis (€)**: Wird automatisch aus dem Bruttopreis und dem eingestellten MwSt-Satz berechnet

#### Bereich: Bemerkung
- **Titel**: Titel der Bemerkung
- **Text**: Detaillierte Beschreibung

### Leistung bearbeiten

1. Wählen Sie eine Leistung in der Liste aus
2. Doppelklicken Sie auf den Eintrag
3. Ändern Sie die gewünschten Felder
4. Klicken Sie auf **Speichern**

### Leistung löschen

1. Wählen Sie die zu löschende Leistung aus
2. Klicken Sie auf das **Löschen-Symbol**
3. Bestätigen Sie die Löschung im Dialog

**Hinweis**: Leistungen, die bereits von Mitgliedern verwendet werden, können nicht gelöscht werden.

## Tipps

- Die MwSt-Sätze können in den **Einstellungen** unter "Stammdaten" geändert werden
- Der Nettopreis wird immer automatisch berechnet: `Bruttopreis / (1 + MwSt/100)`
- Änderungen an einer Leistung ändern **nicht** die Preise bestehender Verträge
