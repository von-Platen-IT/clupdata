# Datenübertragung-Menü

## Übersicht

Das Datenübertragung-Menü enthält alle Funktionen zum Importieren, Exportieren und Sichern Ihrer Daten.

## Import

### CSV Import

Importieren Sie Daten aus einer CSV-Datei in die Anwendung.

**Unterstützte Formate:**
- Mitgliederdaten
- Leistungsdaten
- Warendaten

**Vorgehensweise:**
1. Öffnen Sie **Datenübertragung > Import > CSV Import**
2. Wählen Sie die CSV-Datei aus
3. Ordnen Sie die Spalten den Datenbankfeldern zu
4. Überprüfen Sie die Vorschau
5. Klicken Sie auf **Importieren**

### Datenbank-Restore

Stellen Sie ein ранее erstelltes Datenbank-Backup wieder her.

**Vorgehensweise:**
1. Öffnen Sie **Datenübertragung > Import > Datenbank-Restore**
2. Wählen Sie die Backup-Datei aus
3. Bestätigen Sie den Restore-Vorgang

**Warnung**: Der Restore überschreibt die aktuelle Datenbank!

## Export

### CSV Export

Exportieren Sie Daten in eine CSV-Datei.

**Vorgehensweise:**
1. Navigieren Sie zur gewünschten Liste (Mitglieder, Leistungen, etc.)
2. Öffnen Sie **Datenübertragung > Export > CSV Export**
3. Wählen Sie die zu exportierenden Felder
4. Klicken Sie auf **Exportieren**

### PDF erstellen

Erstellen Sie PDF-Dokumente aus den aktuellen Daten.

**Vorgehensweise:**
1. Navigieren Sie zur gewünschten Liste
2. Öffnen Sie **Datenübertragung > Export > PDF erstellen**
3. Wählen Sie die Export-Optionen
4. Klicken Sie auf **Erstellen**

### Ausdrucken

Drucken Sie die aktuelle Listenansicht direkt aus.

### Datenbank-Backup

Erstellen Sie ein vollständiges Backup der Datenbank.

**Vorgehensweise:**
1. Öffnen Sie **Datenübertragung > Export > Datenbank-Backup**
2. Wählen Sie den Speicherort
3. Klicken Sie auf **Sichern**

**Tipp**: Regelmäßige Backups schützen vor Datenverlust!

## Tipps

- Der Backup-Ordner kann in den **Einstellungen** konfiguriert werden
- CSV-Dateien können in Excel oder anderen Tabellenkalkulationen geöffnet werden
- PDF-Exporte können individuell konfiguriert werden
