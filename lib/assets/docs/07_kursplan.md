# Kursplan

## Übersicht

Der **Kursplan** zeigt auf einen Blick, welche Kurse an welchen Wochentagen und
zu welchen Uhrzeiten stattfinden. Da sich Kurse über die Zeit ändern können,
können Sie **mehrere Kurspläne** anlegen – jeder Plan gilt für einen bestimmten
Zeitraum (mindestens eine Woche).

Jeder Kurstyp ist **farblich eindeutig** gekennzeichnet, so erkennen Sie Ihre
Kurse sofort wieder.

## Die Wochenansicht

```
Zeit   │  Montag   │  Dienstag  │  Mittwoch  │ … │  Sonntag
  16:30 │ ████████  │            │            │   │
  17:00 │ Boxen     │            │  Kickboxen │   │
  17:30 │ Erwachsene│            │  17:00–    │   │
  18:00 │ 16:30–    │            │  18:30     │   │
```

- **Spalten**: Die sieben Wochentage (Montag bis Sonntag) mit Datum
- **Zeilen**: Die Uhrzeiten von 06:00 bis 22:00 Uhr (30-Minuten-Schritte)
- **Farbige Blöcke**: Die Kurse mit Name und Uhrzeit
- **Legende** unten: Welche Farbe gehört zu welchem Kurs

## Durch die Wochen navigieren

| Aktion | Bedeutung |
|--------|-----------|
| **◀ / ▶** | Eine Woche zurück / vor |
| **Heute** | Zur aktuellen Woche springen |
| **Plan-Auswahl** | Für die angezeigte Woche gilt normalerweise automatisch der passende Plan. Wenn sich zwei Pläne überschneiden, wählen Sie den gewünschten aus |

## Kurse anlegen (Kurstypen)

Kurse sind die **Vertragsarten/Kurstypen** (z. B. „Boxen Erwachsene",
„Kinderkurs"). Jeder Kurs hat eine Farbe für die Darstellung im Plan.

1. Klicken Sie auf **„Kurse verwalten…"**
2. Über **„Neuer Kurs"** legen Sie einen Kurs an:
   - **Name**: z. B. „Boxen Erwachsene"
   - **Kampfsportart**: z. B. „Boxen", „Kickboxen"
   - **Farbe**: Wählen Sie aus der Farbpalette – die Farbe erscheint im Kursplan
3. Mit dem **Stift-Symbol** bearbeiten, mit dem **Mülleimer** löschen

**Hinweis**: Ein Kurs, der bereits im Kursplan verwendet wird, kann nicht
gelöscht werden – entfernen Sie zuerst seine Termine.

## Kurspläne anlegen

Ein Kursplan bündelt alle Termine einer Saison oder Phase (z. B.
„Winterplan 2026/27").

1. Klicken Sie auf **„Pläne verwalten…"**
2. Über **„Neuer Kursplan"** legen Sie einen Plan an:
   - **Name**: z. B. „Winterplan 2026/27"
   - **Gültig von**: Erste Woche des Plans
   - **Gültig bis** *(optional)*: Letzte Woche – ohne Angabe gilt der Plan
     unbegrenzt
3. **Termine hinzufügen**: Für jeden Kurstermin wählen Sie:
   - **Tag** (Montag bis Sonntag)
   - **Kurs**
   - **Von / Bis** (Uhrzeiten im Format `HH:mm`, z. B. `18:00`)
4. Über **„Termin hinzufügen"** ergänzen Sie weitere Zeiten,
   über das **Mülleimer-Symbol** entfernen Sie einen Termin

**Wichtig zu den Gültigkeitszeiten:**
- Die Angaben werden auf **Wochenanfänge (Montage)** gerundet
- Ein Plan gilt für die ganze Woche, in die „Gültig von" fällt
- Überschneiden sich zwei Pläne, gilt der **später begonnene** Plan

## Typischer Ablauf im Vereinsjahr

1. Saisonbeginn: Neuen Plan (z. B. „Winterplan") anlegen und Termine eintragen
2. Während der Saison: Wochenansicht nutzen – der passende Plan wird automatisch
   angezeigt
3. Nach Saisonende: Neuen Plan (z. B. „Sommerplan") mit späterem Gültigkeitsbeginn
   anlegen – der alte Plan bleibt erhalten und kann später wieder angezeigt werden

## Tipps

- Über die **Legende** sehen Sie sofort, welche Farbe zu welchem Kurs gehört
- Für Änderungen mitten im Jahr legen Sie am besten einen **neuen Plan** an –
  so bleibt die Historie erhalten
- Termine mit gleicher Uhrzeit (z. B. zwei Kurse parallel) werden im Raster
  nebeneinander dargestellt
