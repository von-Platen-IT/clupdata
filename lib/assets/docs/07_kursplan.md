# Kursplan

## Übersicht

Der Kursplan bietet eine übersichtliche Darstellung aller geplanten Kurse und Termine. Hier können Sie Trainingszeiten, Workshops und andere Veranstaltungen verwalten.

## Funktionen

### Kalenderansicht

- **Monatsansicht**: Übersicht aller Termine im Monat
- **Wochenansicht**: Detaillierte Wochenansicht
- **Tagesansicht**: Alle Termine eines Tages

### Termin erstellen

1. Klicken Sie auf den gewünschten Tag
2. Oder nutzen Sie das **"+"-Symbol**
3. Füllen Sie die folgenden Felder aus:

#### Felder im Dialog
- **Titel**: Name der Veranstaltung
- **Datum**: Datum des Termins
- **Uhrzeit von**: Beginn
- **Uhrzeit bis**: Ende
- **Beschreibung**: Details zur Veranstaltung
- **Leistung**: Zugehörige Leistungsart

### Termin bearbeiten

1. Klicken Sie auf den Termin im Kalender
2. Ändern Sie die gewünschten Felder
3. Klicken Sie auf **Speichern**

### Termin löschen

1. Wählen Sie den Termin aus
2. Klicken Sie auf das **Löschen-Symbol**
3. Bestätigen Sie die Löschung

## Tipps

- Die Kalenderansicht kann nach **Leistung** gefiltert werden
- Wiederkehrende Termine können als Serie angelegt werden
