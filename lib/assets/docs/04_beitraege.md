# Beiträge

## Übersicht

Der Bereich "Beiträge" dient der Verwaltung von Mitgliedsbeiträgen und Rechnungen. Hier können Sie Beiträge anlegen, den Zahlungsstatus verfolgen und Statusänderungen dokumentieren.

## Funktionen

### Datenübersicht

Die Beitragsliste zeigt folgende Informationen:

| Spalte | Beschreibung |
|--------|-------------|
| Rechnungs-Nr. | Eindeutige Rechnungsnummer (Format: RE-YYYY-XXXXX) |
| Mitglied | Name des Mitglieds |
| Leistung | Art der gebuchten Leistung |
| Kontiert am | Datum der Erstellung/Fälligkeit |
| Status | Aktueller Zahlungsstatus (farbig hervorgehoben) |
| Statusdatum | Datum der letzten Statusänderung |

### Status-Farben

| Status | Farbe | Bedeutung |
|--------|-------|-----------|
| kontiert | 🟡 Hellgelb | Neu angelegter Beitrag |
| offen | 🟠 Hellorange | Ausstehende Zahlung |
| bezahlt | 🟢 Hellgrün | Vollständig bezahlt |
| angemahnt | 🔴 Hellrot | Zahlungserinnerung versandt |
| storniert | ⚪ Hellgrau | Stornierte Rechnung |
| inkasso | 🩷 Pink | An Inkasso übergeben |

### Neuen Beitrag erstellen

1. Klicken Sie auf das **"+"-Symbol** in der Symbolleiste
2. Oder nutzen Sie das Menü **Erstellen > Rechnungslegung**
3. Füllen Sie die folgenden Felder aus:

#### Felder im Dialog
- **Mitglied suchen**: Suchen Sie über Vor- und Nachname
- **Leistung suchen**: Wählen Sie die gebuchte Leistung
- **Beitrag (€)**: Wird automatisch übernommen, kann aber überschrieben werden
- **Kontiert am**: Datum der Kontierung (Standard: heute)
- **Status**: Wird automatisch auf "kontiert" gesetzt

**Hinweis**: Die Rechnungsnummer wird automatisch generiert.

### Beitrag bearbeiten

1. Wählen Sie einen Beitrag in der Liste aus
2. Doppelklicken Sie auf den Eintrag
3. Ändern Sie die gewünschten Felder

#### Status ändern

Wenn Sie den Status ändern, müssen Sie zwingend eine **Bemerkung** eingeben, die den Grund für die Änderung erklärt. Dies wird in der Status-Historie dokumentiert.

### Status-Historie

Jede Statusänderung wird automatisch protokolliert:

- Datum und Uhrzeit der Änderung
- Neuer Status
- Begründung (Pflichtfeld)

Die Historie ist im Bearbeitungsdialog einsehbar und kann nicht nachträglich geändert werden.

### Beitrag löschen

1. Wählen Sie den zu löschenden Beitrag aus
2. Klicken Sie auf das **Löschen-Symbol**
3. Bestätigen Sie die Löschung im Dialog

**Hinweis**: Beim Löschen eines Beitrags werden auch alle zugehörigen Status-Verlaufseinträge gelöscht.

## Tipps

- Die **Suchfunktion** ermöglicht schnelles Finden von Beiträgen
- Die Spalten können **sortiert** und **gefiltert** werden
- Statusänderungen sind **nicht rückgängig** zu machen
- Die Bemerkung zu jedem Beitrag kann im unteren Bereich bearbeitet werden
